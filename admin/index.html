Acceso privado

Ingresá con tu cuenta de administración de Supabase. No compartas tu contraseña.

Si ya confirmaste tu correo, ingresá directamente con tu contraseña. Si el enlace de confirmación venció, usá «Reenviar confirmación» y abrí el mensaje más reciente. Solo las cuentas autorizadas pueden administrar los documentos.

Cuenta autenticada, pendiente de autorización

El usuario inició sesión, pero todavía no figura en la lista de administradores. Revisá los permisos y presioná «Comprobar acceso».

Supabase no tiene activa su API de datos. Entrá a Integrations → Data API, habilitá Enable Data API y verificá que figure el esquema public. Después volvé y pulsá «Comprobar acceso».
